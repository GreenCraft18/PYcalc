# PYcalc
Welcome to `PYcalc`!  
`PYcalc` is my first useful Python project and also first calculator!  
I'm not very productive, so I might not update it very often, but if you ever need a Python calculator, here you go!  
# How to Use
1. Go to the releases and just download the `PYcalc.py` script.
2. Run it.
You're done!  
Here are the supported operations:  
+, -, *, /, ^ or **  
sqrt(x) or √, sin(x), cos(x), tan(x)  
π or pi  
For math functions like `sqrt`, `sin`, and etc, they require parenthesis around the argument.  
All the math functions except for `sqrt` use radians and not degrees. (for now)

You can modify the code of the script however you like.
